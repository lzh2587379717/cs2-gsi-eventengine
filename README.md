# CS2 GSI Event Engine

CS2 GSI Event Engine is an event-driven framework for processing and extending data from the Counter-Strike 2 Game State Integration (GSI) protocol.

## Requirements

- **Java**: 25 or later
- **Gradle**: 9.4.x or later (Gradle Wrapper included)

## Building from Source

### Clone

```bash
git clone https://github.com/lzh2587379717/cs2-gsi-eventengine.git
cd cs2-gsi-eventengine
```

### Build

```bash
# Linux/macOS
./gradlew clean build

# Windows
gradlew.bat clean build
```

### Run

```bash
# Linux/macOS
./gradlew bootRun

# Windows
gradlew.bat bootRun
```
